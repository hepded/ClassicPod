## Проверка содержимого

Прочитаны исходники OAuth/Keychain, runtime-настроек и тестовые фикстуры. Client ID читается из UserDefaults; токены — из Keychain, а не из файла исходников. Проверка не читала пользовательский Keychain или библиотечный индекс.

Текстовые файлы source-архива проверены эвристиками на абсолютные домашние пути, private-key headers, типичные GitHub/JWT/Bearer-токены и литерал Client ID. Совпадений не найдено. Строки initial/refreshed/new-token в тестах — искусственные фикстуры, не рабочие credentials. Относительные Markdown-ссылки проверены; недостающих локальных целей не найдено. Workflow YAML синтаксически разбирается.

Это ограниченная проверка содержимого, **не профессиональный security-аудит и не гарантия отсутствия всех секретов**. Специализированный secret scanner не запускался. Истории Git в каталоге проекта нет, поэтому исторические коммиты не проверялись. Если добавите проект к существующему репозиторию, проверяйте его историю отдельно.
